# 交互原型

双击 `index.html` 就能看：单文件（二维码已内嵌）、不需要装 DSH、不需要起服务、不联网。

## 能试什么

- 顶部切换 5 个场景：模型对比 / 代码排错 / 跑题 / **追问（带上下文）** / 拒答。
- 动作行里的 `◆ 质量 … · 关联 …%`：点击打开右侧质量报告。
- 报告：五维条形、话题关联与意图标签、证据引文、**提示词调优建议（展示“在提问后追加”，复制完整改写）**、评分标签明细。
- 右上角：
  - `动作行评分`：关掉后动作行保持原生、不占位。
  - `模拟 Jev 精评`：1.2s 后把本地分升级为"Jev 精评"（**模拟**，不联网）。
- `分享卡片`：预览分享卡，并可下载 PNG。

## 哪些是真的

| 项 | 真实性 |
|---|---|
| 评分、五维、关联度、证据、建议、标签 | ✅ 直接运行 `lib/scoring.js`，与插件同一套代码 |
| Chip / 报告 UI / 交互 | ✅ 与插件 `lib/client.js` 的布局、文案、颜色一致（原型用 HTML 重写，插件用 React.createElement） |
| Jev 精评 | ⚠️ 模拟：本地分 +3，延迟 1.2s |
| 分享卡下载 | ✅ Canvas 生成，但二维码为占位（插件将用真实二维码） |
| DSH 集成（slot / 路由 / 持久化） | ❌ 原型不启动 DSH；真集成见 `lib/host.js` / `lib/client.js` |

## 重新生成

改完 `template.html` 或 `lib/scoring.js` 后：

```sh
node prototype/build.mjs
# → prototype/index.html（自包含，约 55KB）
```

参数：`index.html?demo=1&panel=1` 直接打开第 2 个场景的报告；`?share=1` 打开分享卡；`?jev=1` 显示精评后状态（便于截图）。
